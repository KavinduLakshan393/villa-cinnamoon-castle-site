# Villa Cinnamoon Castle — Selected Website Images

This package contains 21 selected original photographs organized for a parallax / 3D scrolling real-estate website.

## Suggested scroll sequence

1. **Arrival & exterior** — hero facade, property sign, garden reveal, parking, entry porch and night ambience.
2. **Tropical setting** — balcony and garden views for slow parallax transitions.
3. **Shared spaces** — living/dining, staircase, double-height ceiling, upper landing and workspace.
4. **Kitchen & amenities** — full kitchen plus cooking/laundry equipment.
5. **Bedrooms & bathroom** — five visually distinct bedroom images and the hot-water shower.

## Recommended treatment

- Use `01_hero_exterior_day.jpg` as the opening full-screen image.
- Use `03_garden_gate_reveal.jpg`, `06_exterior_night_ambience.jpg`, `10_staircase_living_flow.jpg`, and `11_double_height_stair_detail.jpg` for layered 3D/parallax movement because they contain clear foreground, midground and background planes.
- Use landscape images as full-width scenes where possible.
- Use portrait images in staggered cards, pinned panels, depth stacks or masked transitions rather than stretching them across a desktop viewport.
- Preserve the original aspect ratio and avoid heavy sharpening; several source images are modest resolution.
- The CSV manifest maps every renamed image to its original filename and recommended role.
